# הבית שלנו

אפליקציית ניהול משק בית (PWA) לשני משתמשים.

- הקוד כאן ציבורי, כי ככה GitHub Pages עובד בחשבון חינמי. **אין כאן נתונים.**
- הנתונים יושבים במאגר פרטי נפרד. רק משתמשים שהוזמנו אליו, עם מפתח גישה אישי, יכולים לקרוא ולכתוב אותם.
- `index.html` נבנה מתוך `build.py` (מקור העיצוב והלוגיקה: האפליקציה ב־claude.ai), עם שכבת נתונים מ־`src/data-github.js`.

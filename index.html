איך יוצרים מפתח?
  1. נכנסים ל־github.com/settings/personal-access-tokens/new.
  2. שם: "הבית שלנו". תוקף: עד שנה.
  3. Resource owner: demoza931-pixel. Repository access: Only select repositories, ובוחרים habayit-data.
  4. Permissions, Repository permissions: Contents: Read and write, וגם Actions: Read and write (כדי שמחיר של מוצר חדש יגיע תוך דקות ולא תוך שעה).
  5. Generate token, מעתיקים ומדביקים כאן.
